# 将棋 vs チェス

将棋の駒とチェスの駒が **同じ 9×9 の盤で戦う** 異種格闘ボードゲームです。
ブラウザだけで動き、インストール不要。

- **ふたりで対戦** — 1 台の端末で交互に指す
- **CPU と対戦** — 簡易 AI（2 手読み）と対戦
- **オンライン対戦** — 部屋コード／招待リンクで友だちと P2P 対戦（チャット・再戦つき）

▶ 遊ぶ: `https://<ユーザー名>.github.io/Japanese-Chess-vs.-Chess/`（GitHub Pages を有効化した後）

## ルール

| | 将棋軍（下） | チェス軍（上） |
|---|---|---|
| 初期配置 | 本将棋の平手そのまま | ♜♞♝♞♚♛♝♞♜ ＋ ポーン 9 枚 |
| 強み | **取った駒を持ち駒として打てる** | 駒そのものが強力（クイーン・ルーク・ビショップ） |
| 成り／昇格 | 敵陣 3 段で成れる（行き所のない駒は強制成り） | ポーンが最下段で Q/R/B/N に昇格 |
| 取った駒 | ポーン→歩、ナイト→桂、ビショップ→角、ルーク→飛、クイーン→飛 | 盤から取り除くだけ |

- 先手はチェス軍。
- 相手の王（玉／キング）を **詰ませたら勝ち**。自玉が取られる手は指せない。
- 指せる手がなく王手もかかっていなければステイルメイトで引き分け。400 手で引き分け。
- 将棋軍は二歩・打ち歩詰め禁止、最奥段への歩・香、奥 2 段への桂の打ち込み禁止（本将棋どおり）。
- チェス軍のポーンは初手のみ 2 マス前進可。キャスリング・アンパッサンはなし。
- チェス軍は 9 列に合わせてナイトが 1 枚多い（駒の強さ vs 持ち駒の再利用でバランスを取る設計）。

## オンライン対戦のしくみ

[PeerJS](https://peerjs.com/)（WebRTC）でブラウザ同士を直接つなぎます。
接続の仲介には PeerJS の無料公開サーバーを使うため、**自前のサーバーは不要** で GitHub Pages だけで動きます。

1. 片方が「オンライン対戦」→ 陣営を選んで「部屋を作る」
2. 表示された 6 文字のコード、または「招待リンクをコピー」したリンクを相手に送る
3. 相手がコードを入力（またはリンクを開く）すると対局開始

両者が毎手ルールエンジンで合法性を検証し、食い違いがあればホスト側の棋譜で同期し直します。

> 注意: 一部の企業ネットワークや厳しい NAT 環境では WebRTC が通らないことがあります。
> 自前の PeerJS サーバーを使う場合は URL に `?peerHost=example.com&peerPort=443&peerPath=/` を付けてください。

## GitHub Pages で公開する

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. デフォルトブランチに push すると `.github/workflows/pages.yml` がテスト後に自動デプロイ

## 開発

```sh
npm test                 # ルールエンジンのテスト（Node 18+）
python3 -m http.server   # http://localhost:8000 で起動
```

| ファイル | 内容 |
|---|---|
| `js/engine.js` | ルールエンジン（合法手生成・詰み判定・CPU）。DOM 非依存 |
| `js/app.js` | 画面描画と操作、オンライン対局の進行 |
| `js/net.js` | PeerJS による P2P 通信 |
| `js/vendor/peerjs.min.js` | PeerJS 1.5.4（MIT） |
